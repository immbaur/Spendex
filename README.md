# Spendex

A self-hosted personal finance dashboard running locally on macOS, accessible from any device via a public HTTPS URL through Cloudflare Tunnel.

## Overview

Spendex is a single-user personal finance web app designed to be hosted on a MacBook and accessed from any browser. It connects to Chase bank accounts via Plaid, categorizes transactions, visualizes spending, generates reports, and includes a chat interface powered by the Claude API for custom queries and visualizations.

## Features

- **Bank Integration** — Connects to Chase accounts via Plaid for automatic transaction syncing
- **Transaction Categorization** — Automatically categorizes spending
- **Spending Visualizations** — Charts and dashboards to track where money goes
- **Reports** — Generate summaries and breakdowns of financial activity
- **AI Chat Interface** — Ask questions about your finances and get custom visualizations, powered by the Claude API
